# Planstrand online-wrapper status

Planstrand has no hosted web application or distributed Android online wrapper. The inherited wrapper can be explored with a local development server; mobile distribution is deferred. Its application IDs and default endpoint remain inherited and must be reviewed before use.

See [Android development](README.md), [offline build guidance](README_OFFLINE.md), and the [local frontend setup](../CONTRIBUTING.md#development-setup).
