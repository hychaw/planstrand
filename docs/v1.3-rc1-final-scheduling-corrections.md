## Root causes

1. The shared WorkSession menu exposed reminders, completion and removal, but no exact-time editor. Dragging and resizing use the five-minute grid. The existing Task scheduling dialog accepts precise start times, but creates a new session and does not edit both boundaries of a selected session, so reusing that save path would introduce duplicates. WorkSessionService.update already supports exact timestamps, identity-preserving changes and persistent operations.
2. The timed creation placeholder explicitly supplies `dueDay: null`, suppressing TaskService.add's implicit Today placement, and then creates only a WorkSession. It never adds the independent Planning record required by Focus. In addition, the placeholder parsed time in the system timezone, while Calendar uses the configured timezone, and Today Focus used the system date. These dates can differ at a timezone boundary.

## Changes

- Added **Edit start and end times** to the shared WorkSession context menu used by My Day and Calendar. The small editor reuses Event editor styling, standard date/time fields, existing translations and IANA conversion utilities. Both time fields accept one-minute increments. The displayed timezone follows Calendar configuration; the persisted session timezone remains unchanged.
- Save calls the existing update command with the selected source ID and only `start`/`end`. Task association, completion, creation time and sibling sessions remain intact. No Task deadline, estimate or Planning write is issued. Repeated submission is guarded.
- Separate start/end dates support overnight sessions. Invalid dates, equal/reversed ranges and DST gaps are rejected. Unchanged boundaries retain seconds and the original repeated DST hour. Edited ambiguous wall times follow the existing conversion utility's policy.
- My Day identifies its shared creation placeholder explicitly. A newly created and successfully scheduled Task receives one Today Planning assignment, resolved using the configured Calendar timezone. Date-only creation also uses a single explicit Planning assignment. Calendar Task scheduling and Calendar Event creation do not acquire automatic Planning.
- Existing Task selections and ordinary timed drops do not replan the Task. Removed the day-panel fallback that silently replanned an existing Task when no drop timestamp could be resolved. Explicit date-only planning and Unplan remain available.
- Today Focus projection and its explicit Today Planning gestures now use My Day's configured civil date. Other page modes retain their existing date behavior.
- Reminder scheduling already derives delivery instants from the live WorkSession start and device-local offset, so no new reminder state or scheduling mechanism was introduced.
