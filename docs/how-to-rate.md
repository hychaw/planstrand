# Planstrand feedback

Planstrand RC1 is distributed through [GitHub Releases](https://github.com/hychaw/planstrand/releases), not app stores. Report bugs or propose improvements through [Planstrand issues](https://github.com/hychaw/planstrand/issues); see [Contributing](../CONTRIBUTING.md).

Some inherited application paths still point at upstream rating pages. These do not represent Planstrand store listings.
