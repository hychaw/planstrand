# Planstrand V1

Primary navigation includes Inbox, Master Tasks, Today, This Week, and Calendar /
Schedule. Projects, Tags, Boards, and the upstream Planner remain available.

Master Tasks displays Inbox and all Folders, including empty and nested Folders.
Add Task captures directly into its Folder. The shared add-task bar also defaults
to the Folder being browsed; other primary pages capture into Inbox.
Folder controls create, rename, reparent, reorder, and delete leaf Folders.
Deleting a Folder keeps its Tasks, whose effective ownership becomes Inbox.
Expand/collapse is stored only on this device.

Move Task to Folder opens a destination picker. Dragging a Task to another Folder's
Task list performs the same move. Subtasks follow their top-level Task. Drag a Folder
heading onto another Folder heading to reparent it, or onto the root drop area to
make it a root. Move controls provide keyboard alternatives.

Search covers all Tasks and shows the effective ancestor Folder path. Today and
This Week use independent Planning membership. Use Plan Task to choose Today,
another day this week, week-level placement, or Unplan. Drag between Planning
sections or use the up/down controls to move and order Tasks. Unplan removes only
Planning membership; it does not delete the Task or remove scheduled sessions.

Calendar / Schedule and each Task's Schedule command use WorkSessions. A planned
Task need not have a timed session, and a scheduled Task need not be planned.
