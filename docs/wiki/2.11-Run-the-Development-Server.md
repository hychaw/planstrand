# Run the development server

Use Git, Node.js 22.18.0, and npm 11.18.0.

```sh
git clone https://github.com/hychaw/planstrand.git
cd planstrand
git switch development
npm ci
npm run startFrontend
```

Open the local URL printed by the frontend server (normally port 4200). Run `npm start` in a second terminal to launch Electron. Use a separate browser origin/profile and test data, not your daily planning database.

The local CLI is installed with dependencies; no global CLI installation is needed. See [Contributing](../../CONTRIBUTING.md) for focused tests and [environment setup](../ENV_SETUP.md) for optional integrations.
