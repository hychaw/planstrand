# Inbox View

Inbox is the default capture location in Planstrand's Folder organization.
Open **Tasks** to see Inbox and your hierarchical Folders, or use Folder navigation
below the primary destinations. See [[3.10-Planstrand-V1]] for the V1.3 RC1 guide.

## What the Inbox Is

Inbox holds Tasks with no effective user-created Folder. Capture work here when
you do not yet know where to organize it, then move it into a Folder later.
Folders can be nested to organize related work.

This Folder-based Inbox is distinct from the inherited Inbox Project and
Legacy Capture workflow. Project ownership remains part of the compatibility
model; moving a Task between Planstrand Folders is not a Project reassignment.

## When Tasks Appear in the Inbox

Capture from primary pages defaults to Inbox unless you are adding directly
into a Folder. In Tasks, Add Task within a Folder captures into that Folder;
the shared add-task bar also defaults to the Folder being browsed.

New Tasks created in My Day are planned for Today and appear in Focus.
Their Planning and WorkSessions remain separate from Folder organization.

Deleting a Folder keeps its Tasks; their effective Folder becomes Inbox.
An unavailable Folder page offers a route back to Tasks without deleting Tasks.

## How the Inbox Works

**Quick capture:** Add Tasks before deciding where they belong.

**Progressive organization:** Use Move Task to Folder or drag a Task into another
Folder's Task list. Subtasks follow their top-level Task when it moves Folders.

**Stable organization:** Planning a Task for Today or another date, setting a
deadline, or scheduling a WorkSession does not move it out of its Folder or Inbox.

## Inbox Tasks and Other Features

Inbox Tasks can be planned in Today or This Week and scheduled with WorkSessions
in My Day or Calendar. Planning, deadlines and WorkSessions remain independent;
a due date alone does not put a Task in today's Focus list.

Inherited Tags and time tracking remain available, but they do not define
Planstrand Folder membership.

## Moving Tasks Out of the Inbox

Choose Move Task to Folder from the Task's management context menu and select a
destination, or drag the Task into a Folder's Task list. Planning and scheduling
remain independent of this organizational move.
