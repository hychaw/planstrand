# Downloads and installation

**Planstrand V1.3 RC1** is a Windows x64 prerelease. Download from the
[official release](https://github.com/hychaw/planstrand/releases/tag/v1.3.0-rc.1):

- [Windows Setup](https://github.com/hychaw/planstrand/releases/download/v1.3.0-rc.1/Planstrand-Setup.exe)
  installs the application for the current user.
- [Windows Portable](https://github.com/hychaw/planstrand/releases/download/v1.3.0-rc.1/Planstrand-Portable.exe)
  runs without a traditional installation.

Windows x64 is the currently validated distribution platform. These packages are
unsigned: SmartScreen, Smart App Control or organizational policies may warn about
or block execution. Compare downloads with SHA256SUMS.txt on the release;
checksums verify integrity but do not replace publisher signatures.

Setup and Portable normally use the same default profile at
`%APPDATA%\Planstrand`, separate from the executable. Portable does not
automatically carry your data between computers.

Installation and updates are manual. Close Planstrand completely before upgrading.
First export an independent backup through **Settings → Sync & Backup →
Import/Export**, protect credentials and encryption keys separately, and
[verify restoration](../v1.2-backup-restore.md) in a disposable profile with sync
disconnected. A V1.2 → V1.3 in-place installer upgrade was not tested for this
candidate. V1.2 profiles cannot be opened by V1.1; rollback requires a separate
pre-upgrade backup/profile.

See the [V1.3 release notes](../releases/v1.3.0-rc.1.md) for acceptance results,
compatibility requirements and known limitations, and [[3.10-Planstrand-V1]] to
get started. The [README](../../README.md#local-data-and-privacy) and
[data guidance](3.06-User-Data.md) explain local storage and privacy.
Planstrand provides no hosted SuperSync service; synchronization is optional,
disabled by default and requires separate compatibility checks.
