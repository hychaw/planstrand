# Downloads and installation

**Planstrand v1.0.0-rc.1 is public.** Download the Windows x64 installer or portable build from [GitHub Releases](https://github.com/hychaw/planstrand/releases/tag/v1.0.0-rc.1).

- `Planstrand-Setup.exe` installs the desktop application.
- `Planstrand-Portable.exe` runs the portable build.

These binaries are unsigned and may trigger Windows SmartScreen. Verify source and SHA256 checksums from the release before running them.

Windows x64 is currently validated. Linux, macOS, mobile and store distributions are deferred; locally built web versions are for development. Planstrand does not provide a hosted web or public sync service.

Export an independent backup before migration or updates. See the [README](../../README.md#migration-from-super-productivity) for migration and [data guidance](3.06-User-Data.md) for storage details.
