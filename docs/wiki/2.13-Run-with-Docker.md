# Run with Docker

Planstrand does not publish an official container image or operate a hosted web/sync service. For local development, use the [development server](2.11-Run-the-Development-Server.md).

Docker is useful for local WebDAV and sync-server test services. The [E2E guide](../../e2e/development.md) explains the provider scripts and required flags. Do not expose test-mode services publicly or use production data in them.

The root Compose app service retains an upstream image example for compatibility; it runs Super Productivity rather than a Planstrand release. For Planstrand container experimentation, build the local Dockerfile and review configuration yourself. Container distribution is not a validated RC1 platform.
