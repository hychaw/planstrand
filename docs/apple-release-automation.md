# Apple distribution status

Planstrand does not currently publish macOS App Store or iOS/TestFlight builds. Apple signing, notarization, application identities, and store ownership are deferred. Windows x64 is the validated RC1 distribution platform.

Inherited native build tooling remains for engineering and future validation. It must not be used to distribute Planstrand under upstream application identities or accounts. No Apple deployment workflow is active.

See the [current release runbook](release-and-publishing.md), [release identity decisions](PLANSTRAND_RELEASE_IDENTITY.md), and [GitHub Actions](GITHUB_ACTIONS.md).
