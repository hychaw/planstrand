## Changes

- This Week uses a local, reactive week offset with Previous week, Next week and Current Week controls. Both ends of the displayed range include the year; another week is explicitly identified. Configured week starts and local midnight refresh are retained. Today remains tied to CurrentDateService.
- Week-level and day-level Add/drop actions retain the displayed absolute destination. Quick Today/Tomorrow/This Week/Next Week shortcuts still refer to the actual local date.
- Choose Date and Choose Week use one shared existing date-picker dialog. Existing placements prefill the date; week selection previews and saves the configured week start. Only existing Planning commands write placement operations.
- Compact selector-backed indicators show Unplanned, Today, Tomorrow, a calendar date or Week of a date. Tasks, Inbox and Folder rows include nested tasks. Already grouped Today/This Week tasks omit repeated row indicators; the action panel still shows the current destination.
- The action panel is narrower, separates Planning from Other actions, pairs quick shortcuts, limits scrolling height and reveals itself within the viewport. Escape closes the panel and restores focus to its summary. WorkSession scheduling remains separate.
