# Planstrand v1.3.0-rc.1

Published on October 15, 2026 UTC as a **Windows x64 prerelease**.
[Public release and downloads](https://github.com/hychaw/planstrand/releases/tag/v1.3.0-rc.1).

Planstrand V1.3 RC1 improves everyday planning, precise scheduling, Task menus,
Calendar behaviour, device-local reminders and upgrade safeguards. Core planning
remains local-first and works offline without an account.

## Key changes

- **More flexible Task Planning.** Move Tasks to Today, Tomorrow, This Week or
  Next Week, choose other planning dates, or Unplan them. Navigate previous,
  current and future weeks. Task deadlines, Planning and scheduled WorkSessions
  remain independent.
- **Persistent ordering and clearer menus.** Task order survives restarts. Task
  context menus provide management, Folder movement and Move Up/Move Down;
  three-dot menus provide planning and WorkSession scheduling. Nested Tasks
  receive the same planning controls, with improved keyboard and touch access.
- **Precise WorkSession editing.** Edit start and end times to the exact minute
  from My Day or Calendar, while retaining five-minute drag snapping.
- **Improved My Day creation.** New Tasks created directly in My Day are
  automatically planned for Today and appear in Focus. Scheduling existing Tasks
  continues to preserve their independent Planning assignments.
- **Calendar and timezone corrections.** Calendar weeks follow the configured
  week start, and the current-time indicator uses the correct displayed day.
  British Columbia Windows compatibility includes ICU timezone data 2026b.
- **Device-local reminders.** Add reminders to standalone timed Events and
  WorkSessions at their start or 5, 10, 15, 30 or 60 minutes beforehand. Choose
  Never to disable them. Reminder controls and Windows notification handling
  are improved.
- **Clearer update discovery.** Release-candidate comparisons are handled
  correctly, with the official GitHub release-page fallback retained.
- **Backup and connection safeguards.** Stronger backup write verification and
  unsupported-future-data guards accompany restored default invalid-certificate
  rejection for Electron requests. Updater HTTPS verification remains strict.

## Before upgrading

Export an application-data backup from **Settings → Sync & Backup → Import/Export**.
Keep an independent protected copy outside the application profile and sync
destination, and preserve credentials and encryption keys separately.

Rehearse restoration with sync disconnected in a fresh disposable profile. Close
Planstrand completely before upgrading. Check Tasks, Folders, Planning,
WorkSessions, Events, recurring series, Weekly Templates, archives and settings;
restart and verify again before reconnecting synchronization.

V1.3 retains V1.2's IndexedDB schema 12, operation schema 5 and cross-model version
4.5. There is no V1.3 schema migration. Unchanged schemas do not replace a backup
or guarantee rollback. A genuine V1.2 → V1.3 in-place installer upgrade was not
tested for this candidate; see the verification statement below.

[Backup and restore guidance](https://github.com/hychaw/planstrand/blob/58b9471b92dee0c5fe8bcabf15d3ec194bb47793/docs/v1.2-backup-restore.md)

## Known limitations

- Windows packages are **unsigned**. They ran successfully on the tested Windows
  11 system without disabling Norton or Windows protections, but SmartScreen,
  Smart App Control or organizational policies may warn about or block execution
  on other systems. No security-setting bypass is part of the release procedure.
- Reminders are best effort while Planstrand runs, subject to notification
  permissions, sleep and OS restrictions. Reliable closed-app delivery is
  unavailable; missed or suppressed notifications may not retry.
- Event and WorkSession reminder preferences remain device-local and are excluded
  from synchronization and model-only exports. Recurring and all-day Events do
  not support these reminders.
- Automatic and in-app package downloads remain unavailable. Assisted installation
  and Restart to Update are unavailable; upgrades remain manual.
- Application-data backups/checkpoints are not complete filesystem-profile
  backups or automatic rollback. Protect independent backups and keys separately.
- The BC correction preserves saved timestamps; previously mis-scheduled items
  require intentional editing. Restart after changing the OS timezone while the
  compatibility fallback is active.
- Invalid certificates are rejected. There is no global self-signed-certificate
  bypass; existing explicit Node integration exceptions remain connection-specific.
- Planning retains one placement per Task (`PLANNING_V1`); multi-placement remains
  deferred. Some new interface strings use English fallback.
- Synchronization requires separate provider/server configuration and compatibility
  checks. No hosted Planstrand SuperSync service is provided; do not use the upstream
  hosted service as a Planstrand endpoint. Server, mobile and build-tool security
  follow-ups remain separate from Windows desktop release validation.

## Verification status
