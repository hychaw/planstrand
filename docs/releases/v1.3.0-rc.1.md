# Planstrand V1.3 RC1

Release candidate prepared for approval; not yet published. Windows x64 Setup and
Portable targets use product version `1.3.0-rc.1`. Final packaged Windows
acceptance remains required; development-mode results do not certify those packages.

## Improvements

- Move Tasks to Today, Tomorrow, This Week or Next Week, or Unplan them, from
  their planning actions. Civil dates and your configured week start determine
  placement; Task deadlines and scheduled WorkSessions remain independent.
- Correct British Columbia Windows timezone compatibility and runtime timezone
  rules, aligning Today, This Week and Planning with the local date. Calendar
  Week follows the configured week start, including Monday, and its current-time
  indicator uses the correct displayed day column.
- Persist Task ordering across restarts. Right-click Task menus contain management
  and Move Up / Move Down actions; three-dot menus contain planning and scheduling.
- Improved update notifications compare release candidates correctly and retain
  the official GitHub release-page fallback.
- Add device-local reminders to standalone timed Events and WorkSessions: at
  the start or 5, 10, 15, 30 or 60 minutes before. Choose Never to turn them off.
- More accessible Calendar actions, keyboard access to WorkSession menus and
  clearer reminder guidance, with usability and visual refinements.
- Stronger application-data backup write verification and compatibility guards
  against unsupported future data. V1.2 persistence contracts remain IndexedDB
  schema 12, operation schema 5 and cross-model version 4.5.
- Restore default invalid-certificate rejection for Electron requests, including
  renderer-based synchronization. Existing explicit Node integration certificate
  policies remain scoped to their connections; updater HTTPS verification stays strict.

## Backup and manual upgrade

Before upgrading real data, export an application-data backup from **Settings → Sync &
Backup → Import/Export** in V1.2. Keep an independent protected copy outside the
application profile and sync destination, and preserve encryption keys separately.
Rehearse restoration with sync disconnected in a new disposable profile using the
[backup/restore procedure](../v1.2-backup-restore.md) and
[V1.3 validation record](../v1.3-phase-5b-release-readiness.md).

Close Planstrand completely, then use the normal manual installation process
with the approved Setup package, or replace the Portable executable. Keep the
same intended profile. Check Tasks, Folder ownership, Planning, WorkSessions,
Events, recurring series and occurrence exceptions, Weekly Templates, archives
and settings; close and reopen the app and check again. Retain the original
backup until verification and a fresh independent backup succeed. Stop if
verification fails; do not assume an older version can reopen an upgraded profile.

Packages are unsigned. Windows SmartScreen may warn, and Smart App Control or
organizational policies may block execution. Successful development-mode testing
does not establish that an unsigned package will run on a particular machine;
no security-setting change or bypass is part of the release procedure. Downloads will
be available through [official GitHub Releases](https://github.com/hychaw/planstrand/releases)
after publication approval; no V1.3 assets are published by this preparation.

## Limitations

- Fully assisted in-app installation is unavailable. There is no Install Update
  or Restart to Update action. Production automatic and in-app package downloads
  remain unavailable until owner-authorized trusted release signing and its
  requirements are ready; checksums alone do not authenticate assets.
- Event and WorkSession reminder preferences stay on this device, outside sync
  and model-only JSON exports. Recurring Events and all-day Events do not support
  these reminders. Notifications are best effort while Planstrand runs, subject
  to OS permissions, sleep and restrictions. Missed or suppressed notifications
  may not retry; reliable delivery while closed is unavailable. Actual notification
  visibility must still be checked in the final packaged Windows candidate.
- Protected application-data checkpoints cover supported exported models, not
  complete filesystem profiles, all device settings or automatic rollback. A
  checkpoint on the same disk is not an independent backup. Model exports exclude
  local reminder preferences, separate credentials and operation history; protect
  backup JSON as sensitive data and preserve credentials/encryption keys separately.
- The BC correction preserves saved timestamps. Previously mis-scheduled items
  require an intentional edit. Restart after changing the OS timezone while the
  BC compatibility fallback is active.
- Electron connections with invalid certificates now fail. Self-hosted services
  need a valid trusted certificate unless their existing Node integration exposes
  an explicit connection-specific exception; there is no global self-signed bypass.
- Planning retains one placement per Task (`PLANNING_V1`). Independent
  multi-placement Planning and its migration remain deferred to V1.4.
- Planstrand provides no hosted SuperSync service. Core planning remains usable offline.
