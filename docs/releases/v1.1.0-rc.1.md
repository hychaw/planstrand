# Planstrand v1.1.0-rc.1

Planstrand V1.1 introduces Blue Thread: a clearer, calmer planning experience with
the Strand P identity. Core planning remains local-first and works offline without
an account.

## Highlights

- New Blue Thread light/dark surfaces, sky background, typography, Strand P icons,
  and Comfortable/Compact density options.
- Focused Today, This Week, Tasks, Calendar, and recursive Folder navigation.
  Search, Utilities, Settings, Help, and About are available through the compact
  shell. Nonessential inherited plugin and live-tracking surfaces are hidden.
- Improved Today and This Week planning, including direct Add actions for each
  weekday and Anytime This Week. Current-day context updates across midnight,
  week boundaries, and sleep/resume.
- Calendar Day, Week, Month, and Year views, with distinct Events and WorkSessions,
  clearer creation feedback, and preserved move/resize behavior.
- Multiple independent WorkSessions per Task/day. Moving or resizing one session
  preserves its siblings and the Task's Planning assignment. Individual sessions
  can be completed or reopened without completing their Task.
- Scheduling, Vancouver daylight-saving-time alignment, duplicate projection,
  stale-preview, persistence, and keyboard-focus corrections. App-menu keyboard
  activation and Escape focus restoration have dedicated regression coverage.
- Planstrand-specific version/build information in Settings, About, and Windows
  package metadata; accurate open-source acknowledgements remain available.

## Compatibility

Existing V1 data remains supported; no schema upgrade is required. Tasks, nested
Folders, Planning, standalone Events, WorkSessions, settings, and local-first
operation replay retain their existing domain boundaries. Keep an independent
backup before upgrading and verify the restored workspace before relying on it.

## Known limitations

- **Reset task data is deferred** until safe synchronized cross-domain deletion
  can be guaranteed. This candidate does not expose an unsafe local-only reset.
- Windows x64 packages are unsigned. SmartScreen or organizational application
  controls may warn about or block execution.
- macOS/Linux distribution, store releases, and wider device certification are
  deferred. This candidate does not provide a hosted sync service; live
  multi-device/provider certification was not repeated during release preparation.
- Recurring local Events, reminders, and account/E2EE functionality remain outside
  V1.1.
