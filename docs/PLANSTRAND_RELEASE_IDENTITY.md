Version evidence: tools/git-version.js embeds package version. BackupService uses CROSS_MODEL_VERSION and CURRENT_SCHEMA_VERSION; SchemaMigrationService uses shared integer schema versions. Sync prefixes use model versions. Released-client tests validate schemas independently. UpdateCheckService compares tags with environment.version; builder inherits package version; Android has an explicit monotonic version code. No schema/migration change is justified. Retain 19.1.0; public tag v1.0.0-rc.1.

Additional identity findings: the Windows NSIS tray GUID is replaced with a distinct Planstrand GUID; CONFIG.D_BUS_ID is dormant (no callers) and preserved. Historical Store backup-path fallback remains unreachable for this non-Store RC. Bundled Google Calendar had upstream Desktop/mobile/iOS OAuth defaults; all are removed and authorization is deferred. The production hosted SuperSync URL is blank; users must configure a server they control. Sync namespaces are unchanged.
